# 문제 이름
1091 Shortest Path in Binary Matrix

## 🧩 내 코드의 의도 & 틀리는 반례
- 시작점(0, 0)과 도착점(n - 1, n - 1)이 1로 막혀있는 경우 처리가 필요하다.
```cpp
if(grid[0][0] == 1 || grid[n - 1][n - 1] = 1) return -1;
```
- dist = 1부터 시작해야 한다.

## 왜 틀렸는지
# 이유1. 도착점 검사 위치가 잘못됨
```cpp
while (!q.empty()) {
    if (x == n - 1 && y == n - 1) { return dist; }

    auto cur = q.front();
    x = get<0>(cur);
    y = get<1>(cur);
    dist = get<2>(cur);
    q.pop();
```
여기서 문제는 x, y, dist가 큐에서 꺼낸 현재 값이 아니라 이전 값이라는 점. BFS에서는 먼저 큐에서 꺼내고, 그 꺼낸 좌표가 도착점인지 확인해야 한다.

```cpp
auto cur = q.front();
q.pop();

int x = get<0>(cur);
int y = get<1>(cur);
int dist = get<2>(cur);

if (x == n - 1 && y == n - 1) {
    return dist;
}
```
이 순서로 생각하기
```cpp
while (!q.empty()) {
    1. 큐에서 하나 꺼낸다.
    2. 그 칸이 도착점인지 확인한다.
    3. 아니라면 주변 칸을 큐에 넣는다.
}
```
- 원래 내 코드의 문제점 : 도착점을 큐에서 꺼낸 뒤 큐가 비어버리는 경우 도착점을 검사하지 못하고 아래로 내려간다. (밀린다)

# 이유 2. dist++ 잘못 사용
- dist++는 현재 값을 먼저 사용하고, 그 다음에 1 증가시킨다.
```cpp
q.push({nx, ny, dist++});
```
이 코드는 이렇게 작동한다.
```cpp
q.push({nx, ny, dist});
dist = dist + 1;
```
현재 dist가 3이면 큐에는 3이 들어가고 이후 dist가 4로 바뀐다.
그런데 큐에는 4가 들어가야 하고, dist는 8번 도는 동안 변하지 않아야 한다.
따라서
```cpp
q.push({nx, ny, dist + 1});
```
이렇게 처리하는 게 맞다.

## ⏱️ 시간 복잡도
 # O(N * N)

## 문제 유형
- 최단거리 BFS

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- 시작점 또는 도착점이 `1`이면 바로 `-1`을 반환한다.
- 시작점 `(0, 0)`을 거리 `1`로 큐에 넣고 방문 처리한다.
- BFS에서는 먼저 `q.front()`를 꺼내 현재 좌표와 거리를 확정한다.
- 현재 칸이 도착점이면 즉시 `dist`를 반환한다.
- 8방향 이웃 중 범위 안이고 아직 방문하지 않은 `0` 칸만 큐에 넣는다.
- 다음 칸의 거리는 `dist++`가 아니라 반드시 `dist + 1`로 넣는다.
- 큐에 넣는 순간 `grid[nx][ny] = 1`로 방문 처리해서 중복 방문을 막는다.

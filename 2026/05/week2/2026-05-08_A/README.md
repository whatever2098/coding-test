# 문제 이름
codetree 빙빙 동며 숫자 사각형 채우기 (dx, dy 테크닉)

## 🧩 내 코드의 의도 & 틀리는 반례


## 왜 틀렸는지
```cpp
while (number <= N * M)
```
현재 칸을 채우는 것만 있고, 다음 위치 계산 → 이동 가능 여부 확인 → 방향 전환 → 실제 이동 → 종료 조건이 빠져 있었다.

## ⏱️ 시간 복잡도
 # O(M * N)

## 문제 유형
- 격자 시뮬레이션

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- 달팽이 채우기는 현재 칸에 숫자를 넣고, 현재 방향으로 다음 칸을 미리 계산한 뒤, 격자 밖이거나 이미 채운 칸이면 방향을 (dir + 1) % 4로 꺾고 다시 다음 칸을 계산하는 시뮬레이션 문제다. 총 N * M칸을 채울 때까지 반복한다.

조금 더 짧게 외우면:

>현재 칸 채우기 → 다음 칸 후보 계산 → 못 가면 방향 회전 → 이동을 N * M번 반복한다.

이 때, 
>처음 방향은 오른쪽. 종료 조건은 전체 칸 개수. 다음 칸을 먼저 예상. 격자 밖이거나 이미 채운 칸이면 방향 전환. 오른쪽->아래->왼쪽->위 순서로 회전.

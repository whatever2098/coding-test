# 문제 이름
codetree 작은 구슬의 이동 (dx, dy 테크닉)

## 🧩 내 코드의 의도 & 틀리는 반례


## 왜 틀렸는지
1. 현재 방향으로 실제 좌표 x, y를 바꿈
2. 그 결과가 격자 밖인지 확인함
3. 격자 밖이면 방향만 바꿈

문제점: 벽 밖으로 나간 순간 x, y가 이미 잘못된 좌표가 되어버린다.

또한,
>벽에 부딪혔다는 것은 “벽 밖 좌표로 이동했다”가 아니라, “그 방향으로는 이동할 수 없어서 제자리에서 방향만 바꿨다”는 뜻이다.

그래서 이 문제에서는 실제 좌표를 바로 바꾸면 안 된다.

틀린 사고 흐름:
```text
일단 이동한다 → 밖이면 방향 바꾼다
```
맞는 사고 흐름:
```text
다음 칸을 계산해본다 → 밖이면 이동하지 않고 방향만 바꾼다 → 안이면 그때 이동한다
```
따라서 nx, ny의 가상 위치를 사용한다.

## ⏱️ 시간 복잡도
 # O(T)

## 문제 유형
- 격자 시뮬레이션

## 🔁 다시 풀면 이렇게 한다(복기 문장)
1. 현재 위치 x, y는 바로 바꾸지 않는다.
2. nx, ny로 다음 위치 후보를 만든다.
3. nx, ny가 가능한 위치인지 검사한다.
4. 가능하면 x = nx, y = ny
5. 불가능하면 x, y는 그대로 두고 문제 조건만 처리한다.

>격자에서 벽을 만나는 문제는 실제 좌표를 먼저 움직이면 안 된다. 항상 nx, ny로 다음 위치를 미리 계산하고, 범위 안인지 확인한 뒤에만 x, y를 갱신해야 한다. 이 문제에서 벽 충돌은 이동이 아니라 제자리 방향 전환이다.

# 문제 이름
codetree 1이 3개 이상 있는 위치 (dx, dy 테크닉)

## 🧩 내 코드의 의도 & 틀리는 반례
문제는 각 칸마다 상하좌우 4방향을 확인해서, 인접한 1의 개수가 3개 이상인 칸의 수를 세는 문제이다.

## 왜 틀렸는지
>result의 위치가 잘못됐었음

처음 코드에서는 result가 각 칸을 검사하는 반복문 안에 있었다.
```cpp
for(int i = 0; i < N; i++){
    for(int j = 0; j < N; j++){
        int result{0};
        ...
    }
}

cout << result << "\n";
```

이렇게 하면 두 가지 문제가 생긴다.

첫째, result는 {} 블록 안에서만 살아 있는 지역 변수라서 바깥의 cout에서 사용할 수 없다.
둘째, 설령 출력할 수 있었다 해도, 칸마다 result가 다시 0으로 초기화되기 때문에 전체 개수를 누적할 수 없다.

>따라서 result는 전체 칸을 돌기 전에 한 번만 선언해야 함.

## 💡 핵심 아이디어
1. 모든 칸을 하나씩 확인한다.
2. 각 칸에서 상하좌우 4방향을 확인한다.
3. 격자 밖이면 무시한다.
4. 인접 칸이 1이면 개수를 센다.
5. 인접한 1의 개수가 3개 이상이면 정답을 1 증가시킨다.

## ⏱️ 시간 복잡도
- 모든 칸 한 번 씩 방문한다 했을 때 + 상하좌우 매번 확인하면 4*n*n인데 상수는 소거한다.
# O(n * n)

## 문제 유형
- BFS

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- 격자 문제에서는 먼저 dx, dy로 4방향을 만들고, 각 칸마다 nx, ny를 계산한 뒤 범위 체크를 먼저 한 다음 조건을 검사하겠다. 
- 전체 정답 변수는 칸마다 초기화하지 않고, 반복문 밖에서 한 번만 선언해서 누적하겠다.

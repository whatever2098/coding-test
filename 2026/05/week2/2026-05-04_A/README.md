## 💡 핵심 아이디어
1. 맵 크기 구하기
2. BFS에 필요한 자료구조 준비
3. 시작점 큐에 넣고 방문 처리
4. 큐가 빌 때까지 상하좌우 탐색
5. 도착점 방문 여부에 따라 정답 반환

```cpp
vector<vector<bool>> visited(n, vector<bool>(m, false));
```
각 칸 방문 여부를 기록한다.이 때 default를 꼭 설정한다. 위에서는 false로 n * m을 모두 채운다.

```cpp
visited[0][0] = true;
```
이걸 안 하면 나중에 다른 칸에서 다시 시작점으로 돌아와서 잘못 탐색할 수 있다.

## ⏱️ 시간 복잡도
- 모든 칸 한 번 씩 방문한다 했을 때 + 상하좌우 매번 확인하면 4*n*m인데 상수는 소거한다.
# O(n * m)

## 문제 유형
- BFS

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- 격자에서 상하좌우 한 칸 이동 비용이 모두 같을 때 최단거리는 BFS로 구한다.
BFS는 가까운 칸부터 탐색해야 하므로 queue를 사용하고, 같은 칸을 반복 방문하지 않기 위해 visited 배열을 둔다.
각 칸에 도착했을 때 현재 거리 + 1을 저장하면 도착점의 값이 최단거리가 된다.

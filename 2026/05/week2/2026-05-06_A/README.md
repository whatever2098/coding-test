# 문제 이름
leetcode 695 max area of island 

## 🧩 내 코드의 의도 & 틀리는 반례
BFS로 섬을 탐색하면서 면적을 구하려 했다. 각 칸 순회하다가 1을 만나면 BFS를 수행한다. BFS로 연결된 모든 땅을 탐색하면서 oneArea를 증가시키고 탐색이 끝나면 result와 비교하여 최대값을 갱신하려 했다.

## 왜 틀렸는지
1. 면적 계산 위치 문제
```cpp
oneArea++; //인접 노드 발견 시 증가
```
- 시작 노드를 세지 않음
- '탐색된 노드 수'가 아니라 '이동 횟수'를 세는 느낌이 된다.

2. return 위치 문제
- 첫 번째 행만 탐색하고 종료됨
- 전체 grid를 탐색하지 못함

## 💡 핵심 아이디어
1. 핵심 1: BFS에서 노드 개수는 pop 기준으로 센다.
    - 큐에 들어간 노드는 정확히 한 번씩 pop된다.
2. 핵심 2: 방문 처리는 push 전에 한다.
3. 핵심 3: 전체 grid를 끝까지 탐색한다.

## ⏱️ 시간 복잡도
- 모든 칸 한 번 씩 방문한다 했을 때 + 상하좌우 매번 확인하면 4*n*m인데 상수는 소거한다.
# O(n * m)

## 문제 유형
- BFS

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- BFS에서 노드 개수는 push가 아니라 pop 기준으로 센다.
큐에 들어간 노드는 정확히 한 번 pop되기 때문에 pop 횟수가 곧 노드 수다.
또한 grid 전체를 끝까지 탐색해야 최대값을 구할 수 있다.

> “grid에서 연결된 1들의 덩어리를 찾는 문제라서 BFS/DFS가 필요하다”

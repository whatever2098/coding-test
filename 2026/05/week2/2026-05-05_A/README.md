## 문제 이름
leetcode_200_number of islands

## 🧩 내 코드의 의도 & 틀리는 반례


## 왜 틀렸는지
1. grid는 char 배열인데 '1', '0'이 아니라 정수 1, 0과 비교했다.
2. 처음부터 q에 (0,0)을 넣으면 안 된다.
3. 새로운 섬 조건에 !visited[i][j]가 빠졌다.
4. 함수 마지막에 return cntLand가 없다.
5. 사용하지 않는 cnt 변수가 있다.
6. 방향 반복문의 i가 바깥 반복문의 i와 겹쳐서 헷갈린다.


## 💡 핵심 아이디어
이 문제는 섬의 개수를 세는 문제지만, 알고리즘 관점에서는:

2차원 격자에서 '1'로 이루어진 연결 요소의 개수를 세는 문제라고 볼 수 있다.

>전체 격자를 처음부터 끝까지 순회한다.
이때 어떤 칸이:
```cpp
grid[i][j] == '1' && !visited[i][j]
```
라면, 이 칸은 아직 방문하지 않은 새로운 섬의 시작점이다.

따라서:
```cpp
cntLand++;
```
로 섬 개수를 1 증가시킨다.
그다음 그 위치에서 BFS를 실행해, 상하좌우로 연결된 모든 육지 '1'을 방문 처리한다.

>왜 BFS를 쓰는가?

하나의 섬은 상하좌우로 연결된 육지들의 묶음이다.
즉, 한 번 섬을 발견하면 그 섬에 속한 모든 칸을 한꺼번에 방문 처리해야 한다.

BFS를 사용하면 시작 육지에서부터 상하좌우로 퍼져 나가며 같은 섬에 속한 모든 육지를 찾을 수 있다.

## ⏱️ 시간 복잡도
- 모든 칸 한 번 씩 방문한다 했을 때 + 상하좌우 매번 확인하면 4*n*m인데 상수는 소거한다.
# O(n * m)

## 문제 유형
- BFS

## 🔁 다시 풀면 이렇게 한다(복기 문장)
- 섬 개수 문제에서는 전체 격자를 돌다가 grid[i][j] == '1' && !visited[i][j]인 칸(육지, 방문하지 않은)을 만나면 새로운 섬으로 세고, 그 위치에서 BFS를 돌려 연결된 모든 육지를 방문 처리해야 한다. grid가 char 타입이면 반드시 '1', '0'처럼 문자로 비교해야 한다.
